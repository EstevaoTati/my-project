LAYER 01

The Kernel

One file, CLAUDE.md, loads automatically into every session. It carries the founder's identity, standing priorities, and the questions asked before any significant task — so the system never starts from zero.

Standing Priorities

  1. Protect the founder's time
  2. Increase productivity
  3. Improve decision quality
  4. Build Mwinda Digital
  5. Design scalable systems
  6. Automate everything possible
  7. Maintain perfect organization
  8. Think strategically
  9. Challenge weak ideas
  10. Recommend better alternatives

Before Any Task

  • What is the objective?
  • What is the business impact?
  • What is the fastest solution?
  • Can this be automated?
  • Can this become a reusable system?
LAYER 02

The Agents

Three specialists defined in .claude/agents/. Each carries its own mandate, rules, and output format — invoked by name inside any session, in parallel when the work allows it.

A

Architect

Turns a product idea into a decision-ready design: one concrete architecture, cost at 10 / 1k / 100k users, a weekly build plan — and the strongest alternative it rejected, with reasons.

use the architect agent: design the client-portal SaaS
R

Researcher

Evidence-backed briefs readable in five minutes: bottom line with a confidence level, primary-sourced facts with dates and prices, implications for Mwinda, one sized next step.

use the researcher agent: compare vector DB pricing
S

Strategist

Chief of staff for prioritization and go/no-go calls. Holds a hard cap of three active priorities and challenges anything that smells like building infrastructure before revenue.

use the strategist agent: client cash vs product bet?

LAYER 04

The Memory

Chat is ephemeral; the repository is not. Everything worth keeping is written down, committed, and compounds across sessions.

docs/decisions/

One short file per significant decision, with its rationale — so past reasoning is searchable, not lost.

docs/briefs/

The Monday briefs accumulate into a running record of priorities, trajectory, and what actually shipped.

CLAUDE.md

Self-updating: when the founder states a durable preference, it gets folded back into the kernel itself.
