Confidentialité

Ce que nous collectons

Uniquement ce que vous saisissez dans nos formulaires : nom, adresse email, pays, téléphone (facultatif), votre message et, pour une soumission, les informations sur le manuscrit et le fichier joint.

Pourquoi

Pour répondre à votre demande et, pour un manuscrit, pour l’évaluer. Rien n’est revendu ni utilisé à des fins publicitaires.

Où et comment

Les données sont stockées dans une base de données et un espace de stockage privés, accessibles uniquement à l’équipe éditoriale autorisée. Les manuscrits ne sont jamais publics. Votre adresse IP n’est pas conservée : seule une empreinte irréversible sert à limiter les envois abusifs.

Combien de temps

Le temps nécessaire au traitement de votre demande ou à l’évaluation de votre manuscrit. Vous pouvez demander la suppression de vos données à tout moment.

Vos droits

Vous pouvez demander l’accès, la rectification ou la suppression de vos données via le formulaire de contact.

Ce site n’utilise ni cookie publicitaire ni outil de suivi. Vos préférences d’affichage (langue, version classique, animations) restent dans votre navigateur.
