# LES ÉLITES — content taken from the live site; full multi-page rebuild

Date: 2026-11-01 · Asked by: founder (« prends tout ce qu'on a écrit sur le site »)

## What

- The live site (leselitespublishinghouse.com) is a JavaScript app; plain
  fetches return no text and the sandbox cannot reach it. A GitHub Action
  (`.github/workflows/les-elites-crawl.yml`) renders it with Playwright on
  GitHub's runners and commits text, structure, a screenshot and the app
  bundle to `clients/les-elites/docs/source-site/` (not served).
- Both languages were recovered from the bundle's i18n dictionary.
  `content.js` holds the house's copy FR/EN verbatim; `data/catalog.js`
  holds the 8 books (7 from the live site + *Biblical Politics* from the
  founder's covers) with FR/EN titles, descriptions, genres, languages and
  the one real purchase link (Amazon, *Called to Stand Beside Him*).
- The site is now multi-page, all generated by `scripts/build-pages.mjs`
  from one shell: Accueil (immersive journey), À propos & Mission, Services,
  Publications (filters, featured 3D book), one page per book (drag-to-turn
  3D book), authors, Contact, Manuscrit, Confidentialité.
- Motion layer (`motion.js/.css`): intro and page-transition curtain,
  word-by-word titles, scroll reveals, magnetic buttons, 3D tilt cards,
  draggable 3D books, marquee, gold cursor, ambient dust. Off under the calm
  button; OS reduced-motion keeps footage, drops pointer effects.

## Deliberately NOT carried over

The live app's bundle contains a hidden **testimonials** block (four named
people) and a **stats** block ("Depuis 2020" while the house was founded in
2025; per-domain title counts summing to 65 against a 7-title catalogue).
Neither is rendered on the live site; both read as builder placeholders.
Publishing unverifiable testimonials or figures to prospective authors is a
credibility and consumer-protection risk. Add them back only with real,
consented quotes and sourced numbers.

Social icons on the live site point to "#"; no social link is shown until
real URLs are supplied. The live site's image CDN blocks non-browser
requests (even a headless browser saw broken images), so official covers
come from the founder's uploads.

## Buttons always do something real

Every link is checked by the smoke test (19 pages). Book "Commander" buttons
open the contact form prefilled with the title and request type; the Amazon
button uses the real link. When the form backend is absent (Netlify Drop,
githack), forms hand the message to the visitor's mail app addressed to the
house's real email instead of failing.
