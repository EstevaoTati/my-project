# LES ÉLITES — art direction: warm classic library (founder decision)

Date: 2026-10-31 · Decided by: founder ("B") · Supersedes the visual direction in
`2026-10-31-les-elites-architecture.md` (the technical choices there stand)

## Decision

The House of Knowledge is a **warm classic library**: walnut bookcases on two
levels, carved balustrades, painted vaulted ceiling, brass chandelier, Persian
rugs, green banker's lamps, leather armchair, a neoclassical honey-stone façade.
This replaces the contemporary dark-stone/bronze building of the first cut.

## Why

The founder's reference images (ladder room, lit shelves, scroll corner,
baroque grand hall) all point here. The written brief said the opposite
(« éviter une bibliothèque médiévale… résolument contemporain »), so that was
raised before switching: one building, one style, or the scenes stop reading
as the same place.

## How it was produced

One master keyframe (the Grand Hall), generated from a precise description of
the references; every other scene uses it as an image reference, so materials
and light carry across. The reference images themselves could not be uploaded
from the build sandbox (Higgsfield upload host blocked). See
`clients/les-elites/docs/higgsfield-production.md`.

## Guardrails kept

- Classic, not medieval: no stone dungeons, torches or castle cues.
- The UI palette stays ink / ivory / champagne gold + logo navy; it already
  sits naturally on warm wood.
- No model-drawn titles or logos; spines stay unreadable.

## Standing preference (also in CLAUDE.md)

For Les Élites visuals, the founder's own reference images win over the
written brief when they conflict, after the conflict has been flagged.
